# 跨月份（6/7/8）因子稳定性分析

## 数据

- 统一面板：2400 条 quantitative candidate（6月9天 + 7月13天 + 8月8天，每天80）
- 因子：trigger 当日可得（RSI / MA20 / 量比 / 相对强度 / 周线延伸等）
- 收益：T3/T5 真实结束（entry 用次日开盘，exit 用 T3/T5 收盘）
- 文件：`agents_workspace/trade_plan_backtest_fix2_0617/unified_month_panel.csv`

## 分位示例（更快看出易翻转）

### weekly_close_vs_ma20_pct
- 6月：低→高 = +0.84, +1.02, +0.78, -0.29 （低好）
- 7月：低→高 = +0.71, -0.05, -2.28, -4.08 （低好，更强）
- 8月：低→高 = +2.09, +1.79, +2.90, +4.35 （高好，反转）

### relative_strength_60d
- 6月：q0 +1.40, q3 -0.29 （反向）
- 7月：q0 +0.77, q3 -4.03 （反向）
- 8月：q0 +1.03, q3 +4.25 （正向，翻转）

### short_score
- 6月：q3 +1.88 最高
- 7月：无明显方向
- 8月：q0 +3.90 反而最高

## 结论

**不存在一个简单、跨月份稳定的 T3 因子。** 特别是：

- 多空（追强 vs 低吸）在 8 月反转；
- 7 月本身整体差（可能受市场 regime 拖累）；
- 8 月普涨时只要不追最极端，就算 cutting-edge 也没有；

因此继续做“一个固定选股公式”不会见效。更现实的路径是：

1. **先做 regime/市场状态分类**（如 7 月弱、8 月强），用不同的持仓/过滤；
2. 或直接做 **事件催化型 T3**（不看单因子排序，看具体公告/涨跌/量能配合）；
3. 或把持有期缩短，找那些在 T1/T2 可能更稳的微观波动。
